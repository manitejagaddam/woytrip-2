Overview
Create a modern travel booking website using the MERN stack with a clean and interactive UI. The design should match the given Figma screenshot exactly, incorporating animations, scrolling effects, and color gradients. The website should be fully responsive, ensuring a seamless experience across all devices.

1. Color Palette
Use the following colors to maintain the exact visual aesthetics:

Primary Colors:
Light Blue (#6EC1E4) - Used for header and buttons.
Deep Blue (#2C6FBB) - Used for text highlights and some button hover effects.
Secondary Colors:
White (#FFFFFF) - Used for background and card sections.
Light Gray (#F7F7F7) - Background for subtle contrast.
Dark Gray (#555555) - Text color for readability.
Accent Colors:
Orange (#FFA500) - Used for call-to-action highlights (e.g., leaves decoration).
Soft Yellow (#FFD700) - Secondary accents for warmth.
2. Animations & Effects
Header (Hero Section)
Fade-in Animation: The hero text and buttons should smoothly fade in within 1.5s.
Image Parallax: The image of the traveler should slightly move when the user scrolls.
Button Hover Effect: Change background color from #6EC1E4 to #2C6FBB smoothly over 0.3s.
Scrolling Effects
Smooth Scroll: Apply a smooth scrolling effect across all sections.
Lazy Load Images: Images should load with a fade-in effect.
Parallax Scrolling: The "Why Choose Us" section should have a parallax background effect.
Card Animations (Popular Destinations & Our Destinations)
Hover Effect:
Scale the card up slightly (1.05x).
Apply a box-shadow (0px 5px 20px rgba(0,0,0,0.2)).
Button Hover: Icons should change color and slightly move up.
3. Layout & Structure
Navbar:

Sticky at the top.
Background changes from transparent to white on scroll.
Hero Section:

Centered text with an eye-catching CTA button.
Popular Destinations Section:

Grid layout (grid-template-columns: repeat(4, 1fr);).
Cards have consistent spacing and hover effects.
Why Choose Us Section:

Two-column layout with an image on one side and text on the other.
Light animated elements on bullet points.
Our Destinations Section:

Masonry grid layout with responsive scaling.
Footer:

Social media icons with hover effects (slight scale-up + color change).
4. Responsiveness & Mobile Optimization
Mobile View:

The grid should collapse into 1 column.
Navbar turns into a hamburger menu.
Reduce padding/margins for better fit.
Tablet View:

The grid should display in 2 columns.
Adjust image sizes to maintain proportion.
5. Technologies to Use
Frontend: React (Next.js or Vite) with Tailwind CSS for fast styling.
Animations: Framer Motion for advanced interactions.
Scrolling Effects: GSAP for smooth transitions.
Backend: Node.js with Express.js.
Database: MongoDB for storing travel data and user bookings.
Final Touches
Ensure SEO-friendly meta tags.
Optimize images for faster load times.
Implement dark mode toggle for accessibility.
